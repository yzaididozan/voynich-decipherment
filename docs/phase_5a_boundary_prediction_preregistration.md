## Frozen 15-unit rule

Each locked TEST source is divided into exactly 15 contiguous token-balanced
units.

Preserve TEST line order. For `k = 1..14`, close the current unit after the
first line whose cumulative token count reaches or exceeds `k/15` of the total
TEST token count. Unit 15 receives the remainder.

No source line is split. Every unit must be nonempty.

Models reset at original line boundaries. Per-line scoring is aggregated into
the frozen unit IDs.

## Boundary boost

For each unit:

```text
delta_space_free =
    HMM_space_free bits/event
    -
    matched_trigram_space_free bits/event

delta_token_aware =
    HMM_token_aware bits/event
    -
    matched_trigram_token_aware bits/event

boundary_boost =
    delta_token_aware
    -
    delta_space_free
```

The primary feature is:

```text
boundary_pair_entropy_bits = H(F,I)
```

where `F` is the final glyph of a ciphertext token and `I` is the initial glyph
of the following ciphertext token. Boundary pairs are formed only within the
same original source line.

## Primary decision rule

Within each source × seed run, using the 15 prospective units:

```text
Pearson r(H(F,I), boundary_boost)
Spearman rho(H(F,I), boundary_boost)
```

A run is directionally successful iff:

```text
Pearson > 0
AND
Spearman > 0
```

A language replicates iff:

```text
>= 4/5 seeds succeed
```

Phase 5A supports the prospective prediction iff:

```text
>= 3/4 languages replicate
```

The final labels are:

```text
PHASE_5A_PROSPECTIVE_BOUNDARY_PREDICTION_SUPPORTED

PHASE_5A_PROSPECTIVE_BOUNDARY_PREDICTION_NOT_SUPPORTED
```

There is no magnitude, p-value, or confidence-interval threshold. No rule may
be relaxed after TEST access.

## Why both correlations are required

D3 showed that f57 amplified several Pearson coefficients, while the rank
relationship for cross-boundary pair entropy persisted after sensitivity
exclusions. Requiring positive Pearson **and** Spearman prospectively prevents
one unusually influential unit from being sufficient by itself.

Phase 5A does not require the fresh-control correlations to equal the observed
Voynich magnitudes.

> diagnostics was subsequently predicted in the correct direction by the
